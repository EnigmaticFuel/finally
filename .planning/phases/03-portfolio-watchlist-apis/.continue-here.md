## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Fixture-masked requirement | A fixture performs the exact registration production omits, so the requirement's own test is green while the behavior is unreachable | blocking | Test the unwatched-ticker trade path end-to-end through the lifespan with no cache pre-seeding |
| Probe inherits the test's blind spot | The verifier hand-injected the ticker the same way the fixture does and drew the opposite (wrong) conclusion | blocking | Production-shaped probes only for PORT-07: real lifespan, real simulator, real source |
| Docstring asserting behavior the code lacks | `services/watchlist.py:110-113,135-137` state "the source is started from the watchlist rows on every boot" — false; `main.py:55` starts from `DEFAULT_TICKERS` | advisory | Fix the behavior, then the docstrings; the D-08/D-09 rationale rests on them |

**The three gaps (blocking the phase goal):**

- **G-01 / CR-02 — the auto-add-on-trade path can never fill.** `execute_trade` awaits
  `wait_for_price` (`services/trading.py:103`) *before* opening the transaction, and
  `add_watchlist_ticker` (line 144) lives *inside* it. Nothing on the trade path registers the
  symbol with the market data source, so an unregistered ticker never prices, the 2s wait always
  expires, and `_apply_trade` is never reached. PORT-07 and ROADMAP SC2 fail for exactly the case
  they name.
- **G-02 / CR-01 — boot ignores the persisted watchlist.** `main.py:55` does
  `await source.start(list(DEFAULT_TICKERS))`. A user-added ticker survives restart in the DB but
  gets no feed: null price, silently excluded from `total_value`, unsellable (`wait_for_price`
  400s), unremovable (409, position held). A stranded holding with no in-app recovery short of a
  full reset. This also removes the premise that makes the 409 held-ticker rule safe.
- **G-03 / CR-03 — a dead snapshot task blocks teardown.** When `snapshot_loop` dies of anything
  but `CancelledError`, `await task` re-raises out of the lifespan (`main.py:58-63`), so
  `await source.stop()` at line 63 never runs. The market source and its `simulator-loop` task
  outlive the app. The loop dying is *correct* (PORT-12's raise-don't-swallow); only the blocked
  teardown is the defect.

G-01 and G-02 are the same missing seam from two directions and should be planned together.
