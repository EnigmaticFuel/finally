## Flagged assumptions (unresolved probe items)

The edge probe returned two `unclassified` rows against this plan's requirements. Both are
recorded here rather than dropped, and both stay `unresolved` - a reviewer should confirm the
planner's reading.

- **PORT-05 - unclassified.** "A sell exceeding shares held is rejected with a 400 - no
  shorting" produced no edge category the probe could classify. The planner's reading, which
  the executor implements: *shares held* means the `quantity` on the `positions` row read
  inside the same `BEGIN IMMEDIATE` as the write, not a value read earlier or supplied by the
  client; a ticker with no positions row counts as zero held, so selling one is a 400
  "insufficient shares" rather than a 404; and the rejection fires before any cash is credited,
  with the auto-added watchlist row rolled back alongside it.

- **PORT-09 - unclassified.** "A sell that takes a position to zero deletes the position row
  entirely" produced no classifiable edge. The planner's reading: *takes to zero* is decided by
  `is_zero(remaining)` against the existing 1e-6 epsilon, not by exact float equality, so a
  residue left by repeated fractional sells still deletes the row; and *deletes entirely* means
  no row remains in `positions` for that ticker, never a surviving row carrying quantity zero.
  The consequence a reviewer should check is that the trade's own snapshot, written after the
  delete, values the portfolio without that position.
