## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Assuming the verify-work workflow's completion rule governs phase completion | The workflow's `complete_session` step computes `status: complete` when no test is pending, blocked, or skipped-**without**-a-reason — so a justified skip reads as resolved. It is not the gate. `phase uat-passed` is, and `uat-predicate.cjs:43` defines `PASSING_RESULTS = {'pass','passed'}` with `:235` blocking on everything else. I offered "skip with a reason" as a phase-closing option on that basis and it did not close the phase. | advisory | Before presenting any UAT resolution as phase-closing, run `gsd-tools.cjs phase uat-passed <N> --require-verification` and read `blockers[]`. The two rules genuinely disagree; the predicate wins. |
| Trusting the pause-work placeholder grep | The workflow's `grep -l "To be filled\|placeholder\|TBD"` flags 22 files in this repo. Every hit is prose — the word "placeholder" describing `backend/static/index.html` (a deliberate D-11 artifact), and two `TBD` matches that are verification reports *stating no TBD markers were found*. Reporting them as incomplete summaries would be false. | advisory | Grep for the markers with `-n` and read the matched lines before reporting anything as an incomplete summary. |
| Recording a UAT pass over an unverified artifact | Carried from the Phase 1 handoff. Phase 1's UAT test 5 asserted an artifact edit was present when it was not; a plain "pass" would have written a false record. | advisory | When a test's expected state is *an artifact edit*, read the artifact. Action-item tests are not observation tests. |
| Inheriting a stale blocker reason | `02-UAT.md` test 1 carried a "WSL integration is disabled" reason written in a prior session. Re-running the check this session confirmed it still held — but the habit of re-confirming is the point, since accepting a standing assumption on stale evidence is how coverage gaps get quietly laundered into closed items. | advisory | Re-run the blocking check before converting `blocked` into `skipped`/`accepted`. |
