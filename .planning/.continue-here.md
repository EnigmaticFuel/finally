## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |

| Recording a UAT pass over an unverified artifact | UAT test 5 asserted a node-ID correction was present in `01-CONTEXT.md` and `01-VALIDATION.md`. A plain "pass" would have written a false record. | advisory | Before recording a pass on a test whose expected state is *an artifact edit*, read the artifact. Action-item tests are not observation tests. |
| Trusting `phase.complete` warnings at face value | The transition emitted 20 "file not on disk" warnings. All were false: SUMMARY paths resolve relative to `backend/`, not repo root, and several flagged "paths" were shell command strings. | advisory | Check a sample against the filesystem before reporting warnings as real or reporting a transition as clean. |
